# Le Abelaa Mall

Le abelaa Mall est le leiux ou vous trouverez uniquement les boutiques, c'est l'hyper marché d'Abelaa. <br>
Pour accéder au Abelaa Mall, vous devez, à partir de l'une des fonctionnalités de l'application, cliquer sur ***Abelaa Mall*** dans le menu.

## **A quoi sert le Abelaa Mall ?**

Le Abelaa mall permet d'avoir toutes vos boutiques préférées et toutes celle qui existe centralisé au même endroit. Si vous avez une idée exacte de ce que vous chercher ou de qui vous chercher il ne sera plus nécessaire d'aller vous **balader dans la Marketplace**.

## **Comment accéder au Abelaa Mall?**

Pour accéder au **Abelaa Mall** il faut depuis la page d'acceuil de l'application cliquer sur **MarketPlace** puis sur ***Abelaa Mall*** dans le menu.

Une fois à l'intérieur du **Abelaa Mall**  vous avez la possibilité:

- D'acheter et/ou de troquer un article
- De rechercher une boutique
- Parcourir toutes les boutiques d'Abelaa


## **Comment chercher une boutique dans le Abelaa Mall ?**

La fonctionnalité de **Recherche de Listings** vous permet de trouver rapidement une boutique spécifique disponibles dans le Abelaa Mall. Grâce à la barre de recherche vous pouvez facilement identifier les boutiques les plus pertinents pour vous.

### ***Accéder aux Listings du Abelaa Mall***

Pour consulter les listings de boutiques :

1. Ouvrez la section **Marketplace** dans l’application.
2. Sélectionnez un **Groupe d’Inventaire**.
3. Les listings disponibles pour ce groupe s’affichent automatiquement.

Chaque groupe contient les listings publiés par ses membres ou administrateurs.

### *Rechercher par mot-clé*

La fonctionnalité de recherche vous permet de rechercher un article à acheter à partir d’un mot-clé dans une boutique. Effectuez une recherche par mot-clé dans le Abelaa Mall.

1. Cliquez sur la barre de Rechercher.
2. Entrez le mot que vous recherchez dans le champ de recherche.

La liste des produits correspondant seront affichés en bas.

# FAQ

## À propos des notifications

Les notifications ne sont accessibles sur un appareil que si l'utilisateur les a acceptées lors de l'ouverture de l'application. Elles servent à vous tenir informé(e) de tout ce qui se passe concernant vos produits ou commandes en ligne.

## ***Afficher les notifications***

Les notifications de l'application sont visibles dans la barre supérieure, à côté de l'option de sélection de la langue. Cliquez simplement sur la petite icône de cloche pour afficher toutes les notifications reçues. Vous pouvez alors :

- **Marquer comme lu** : En cliquant sur cette option, vous pouvez marquer tous les messages comme lus.
